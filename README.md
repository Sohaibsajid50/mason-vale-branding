# Mason Vale character pack

Reusable branding assets for setting up Mason Vale on another machine.

- `BRAND.md`: identity, content direction, tone, and voice reference.
- `assets/images/`: original headshot, standard webcam look, alternate looks, and ClearTake banner.
- `assets/voice/`: three voice audition samples; audition 1 was selected.
- `references/mason-robot-reaction.mp4`: existing finished video for presentation and editing reference. Verify factual claims independently before reuse or publication.
- `review/`: alternate webcam previews.

## Use on the M1

Clone this private repository with an authorized GitHub account. Give the new channel access to this folder and ask it to read BRAND.md, inspect the standard webcam image, and review the reference video before production. Keep the face and voice consistent; get approval before changing identity.

This is an asset pack, not an OpenMontage installation. Configure production tools and API credentials separately. Never commit secrets.

Source images and audio were copied without modification. Provider logs, queued requests, temporary renders, and credentials are excluded.
